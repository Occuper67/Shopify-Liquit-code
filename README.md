# Shopify Liquid Component Library — GitHub Pages

This is a static GitHub Pages site containing the recovered Shopify Liquid component library.

## Publish
1. Create a new **public** GitHub repository, e.g. `shopify-liquid-library`.
2. Upload **all files in this folder** (not the ZIP itself).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait a minute or two. GitHub will show the live URL.

The site is fully static. No Python, Node, database, or WordPress is required.

## Notes
- 457 recovered component records are included.
- 456 have captured original code; 1 card did not return a code response in the supplied recovery run.
- Browser previews simulate Shopify Liquid variables with demo values. The original code is not rewritten.
- Some snippets may still look different from Shopify because they depend on a live Shopify theme/product context or external assets.
